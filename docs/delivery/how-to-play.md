# 怎么玩这五个交付物

## 一分钟上手

**不想装任何东西**：打开交付包的 `02-players/` 目录，双击里面的 exe 就能玩。
这五个都是 Windows 64 位的独立程序，不需要装 Unity。

**只想看效果**：打开 `04-videos/`，每个交付物一段 8 秒的运行演示。

**想改代码**：用 Unity Hub 打开仓库里的 `tasks/01-…` ~ `tasks/05-…`。
工程已经配好标签、构建场景与输入方式，打开直接按 Play 即可。
需要 Unity **2022.3.62f2** 与 Unity Personal 许可。

---

## 挑战二 · Play Fetch

**操作**：按 **空格** 放出一只狗。

**玩法**：球从天上随机掉下来（三种颜色），你按空格把狗放出去，狗会一路向左跑，
去接掉落的球。球被狗碰到就消失，球掉到画面下方则这一局结束，
控制台会打印 `Game Over`。

**要点**：狗跑得很快（30 单位/秒），横穿整个画面只要 1.4 秒；而球落到地面要 2.4 秒。
所以**看到球掉下来就要立刻按空格**，晚一点狗就白跑了。连续按空格不会刷出一堆狗，
有 0.5 秒冷却。

## 挑战三 · 气球炸弹

**操作**：**按住空格**让气球往上飘，松开就慢慢往下沉。

**玩法**：气球在小镇上空不断上升（背景无缝循环滚动，制造前进的错觉）。
天上会随机掉下金币和炸弹——吃金币有烟花和音效，撞炸弹会爆炸、背景停止滚动，
这一局就结束了。

**要点**：气球有最高高度上限（14），到顶就上不去了。撞到地面会弹起来并有音效，
不会掉出画面。

## 挑战四 · 足球

**操作**：

| 键 | 作用 |
| --- | --- |
| **↑ / ↓** | 把足球往前 / 往后推（相对于摄像机方向） |
| **← / →** | 绕着球场旋转摄像机 |
| **空格** | 冲刺（脚下会冒烟） |

**玩法**：这是"Sumo Battle"的足球版。敌方球会朝**你的球门**冲过来，你要把它们撞出去；
同时也要守住自己的球门，别让它们进去。球有真实的物理惯性，撞上去会互相弹开。

**要点**：

- 吃到的**力量道具**会持续 5 秒，撞球明显更远，脚下有指示器。
- 每清空一波，下一波就多一个敌人，而且**敌人每一波都会更快**。
- 空格冲刺可以用来突然加速抢球。

## 挑战五 · 打地鼠

**操作**：标题界面点 **Easy / Medium / Hard** 选难度开始，然后**用鼠标点击**冒出来的食物。

**玩法**：食物不断在格子里冒出来，点中就加分并炸开一小团火花，
**鼠标只是移过去不会得分**（要点击才得分）。骷髅是陷阱，点到就结束游戏。
左上角实时显示分数，右上角是 60 秒倒计时。

**要点**：难度越高食物冒得越快（Easy 每 2 秒一个，Medium 1.5 秒，Hard 0.75 秒）。
倒计时归零后游戏结束，会出现 **Restart** 按钮，可以直接重开一局。

## 完整游戏 · Raining Apocalypse

**操作**：主菜单点 **Play** 进入游戏，**← / →** 左右移动，**空格**冲刺。

**玩法**：2D 躲避游戏。天上不断砸下障碍物，左右移动躲开它们。
撞到会掉血并有受伤音效，血量显示在左上角，血量归零就出现失败画面，可以重开。
背景会一直向下滚动，障碍物生成得越来越快，坚持越久越难。

**要点**：**空格冲刺**是这一关额外加的（作者公开的工程里没有），
短时间加速，冷却 0.2 秒后可以再冲——躲障碍物或者抢位置时很有用。

## 常见问题

**双击 exe 没有反应 / 一闪而过**
检查一下有没有被 Windows Defender 拦了，把 `02-players/` 整个目录解压出来再运行，
不要在压缩包里直接双击。

**游戏窗口很小或者分辨率不对**
Windows 10/11 上右键 exe → 属性 → 兼容性 → 以 640×480 的窗口运行。

**在 Unity 里打开报缺少脚本或者一片紫**
用 Unity **2022.3.62f2** 打开。其它版本会把工程里的资源重新序列化，
造成没必要的改动。

**想重新生成这些 exe**
```powershell
powershell -File tools/build-project.ps1 -ProjectPath 'tasks/01-challenge-2-play-fetch'
```
