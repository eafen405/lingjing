# 每个挑战与完整游戏各自独立成一个 Unity 工程

四项挑战来自 Create with Code 课程，完整游戏来自另一门 2D 课程，两者的美术资源与脚本互不通用。考核要求把四个挑战**分别**打包交付，因此每个挑战与完整游戏各自独立成一个 Unity 工程，统一放在仓库的 `tasks/` 下平行编号，而不是塞进同一个工程。

## Considered Options

- **一个工程、五个场景**：省掉四套编辑器缓存，但不同挑战里存在同名脚本与同名素材，导入后会互相覆盖；逐个打包时还得反复切换场景
- **完整游戏放仓库根、挑战放子目录**：两个平级的考核产物，一个在根一个在子目录，结构不对称
- **五个独立工程** —— 选中：每个交付物互不干扰，各自出包

## Consequences

仓库里会有五份 `ProjectSettings`，改通用设置（如色彩空间、输入设置）时要同步五处。
