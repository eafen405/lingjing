# 用 Unity 2022.3 LTS 而非 Unity 6 作为编辑器

考核 PDF 建议使用较新的 Unity 版本，最初也据此选定了 Unity 6.3 LTS。但 Unity 6 全系安装包在中国区 CDN 全部返回 404，无论直链还是 Unity Hub 的 headless 安装都取不到；Unity 2022.3 LTS 可正常下载，且它正是 Unity Learn "Create with Code" 课程官方支持的版本之一（6.0 / 6.3 / 2022.3 / 2021.3），课程配套的起始文件也是针对这一代编写的。因此改用 **2022.3.62f2**。

## Considered Options

- **Unity 6.3.27f1**：课程同样支持，但中国区 CDN 404，Hub 与直链两条路都失败
- **Unity 2021.3.45f2**：可下载，比 2022.3 更旧一代
- **Unity 2022.3.62f2**：可下载，且在课程官方支持列表内 —— 选中

## Consequences

2022.3 已不在 Unity 当前的受支持版本列表中。本项目以忠实复刻课程为目标，不追新版本；若后续阶段需要 Unity 6 的新特性，再做升级迁移。
